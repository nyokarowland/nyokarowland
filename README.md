### [Customer-Service Call Monitoring and Scoring Validation](https://github.com/nyokarowland/automated-quality-monitoring)
**Professional team project · QA and process improvement**

**Question:** Do automated call scores reflect required customer-service behaviors?

I conducted test calls, compared automated results with the conversation, identified missed recognition, and helped refine evaluation logic. The case study includes a labeled fictional example of expected-versus-actual scoring. No measured production accuracy improvement is claimed.

### [Software QA Testing Portfolio](https://github.com/nyokarowland/software-qa-testing-portfolio)
**Fictional QA exercise · Testing and release readiness**

**Question:** Can employees submit complete requests and save valid profile information?

I created a test plan, nine test cases, defect reports, a 5 Whys analysis, regression documentation, and a final summary. The fictional scenario identifies two validation defects and documents six passing regression cases after simulated corrections.

### [Customer Registration Web Service](https://github.com/nyokarowland/web-service-registration-architecture)
**Academic design · Requirements and validation**

**Question:** How should registration enforce eligibility and prevent duplicate customer records?

I planned Gmail validation, full-email uniqueness, server-side reCAPTCHA verification, IP-based signals, and MySQL safeguards. The repository explains the architecture and planned tests; the service has not been deployed.

### [MySQL Database Analysis](https://github.com/nyokarowland/mysql-database-analysis)
**Academic database exercise · SQL and business analysis**

**Question:** Where are returns concentrated, and what should be checked before acting on those totals?

I built related customer, order, and return tables and wrote queries for geographic and product summaries. The project explains record verification and the distinction between return counts, share of returns, and return rates.
